# read it like this:
# - the device acts on RCODE + AD only: SERVFAIL = BOGUS = refused, whatever the EDE number. EDE is shown for the log
# - ota.unknownalg: NOERROR with an IP but no ad = INSECURE. It is on the must-be-secure list, so the device REFUSES it: the downgrade is caught
#   (the gateway alone could not catch it: see results/02)
# - ota.unsigned is refused for the same reason; an unsigned name that is not on the list would be used (INSECURE, use IP)
# - ede values (7, 8, 6, 10, 6) match the kdig results 01, 03, 04. nosig = 10 (RRSIGs Missing), nokey = 6 (Unbound's choice, RFC predicts 9)
# - handshake 2081 ms (results/14: 1684 ms): the variance between runs is a Wi-Fi/hotspot effect, to be measured in the benchmarks
